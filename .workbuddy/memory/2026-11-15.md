## 第 10 步：GitHub CLI（gh）安装与登录
- 安装：系统原来无 gh。官方最新 v2.104.0，GitHub 直连下载被拦（502），npmmirror/tuna/ustc 均无 gh 镜像，改用 ghproxy.net 代理（断点续传 8 轮才下完 14.5MB）。SHA256 08c06d10…c879e5 与官方一致，签名 GitHub, Inc.（微软 CA）。解压 `%LOCALAPPDATA%\Programs\gh\gh.exe`，写入用户 PATH，免提权

- 代理坑：agent 环境有 HTTP_PROXY=127.0.0.1:54985，该代理对 api.github.com 通但 github.com 不通，导致 gh device flow 轮询超时。运行 gh 必须 `env -u HTTP_PROXY -u HTTPS_PROXY`
- 登录：`gh auth login --web --git-protocol ssh` 非 TTY 下可用（会打印 one-time code 并轮询）。前两次 device code 15 分钟过期（用户未及时操作）；第三次轮询 TCP 超时（热点切 IP）；第四次成功。账号 jianjiaying2026，token 存 keyring
